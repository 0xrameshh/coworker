# Project Guidelines for Claude

## Tech Stack
- Node.js, TypeScript, Vite, React, Electron

## Coding Methodology
- Maximum file size: 350 lines
- Run tests after every meaningful code change
- Maintain clean, organized folder structure

## Git Rules
- Only commit when explicitly asked by the user
- Never push without user permission

## Privacy Rules
- Never expose or leak user's personal information
- Never include system usernames, paths, or identifying information in outputs, commits, or code
- Sanitize any file paths before displaying or committing
